# Instructions for AI agents

This repository contains an open-source mission-pack framework. It does not contain the private HEROES application.

Before changing files, read README.md, CONTRIBUTING.md, docs/mission-pack-format.md, docs/ethical-guidelines.md, and docs/accessibility.md.

## Rules

- For community contributions, modify only the assigned file under packs/es.
- Never modify LICENSE, README, settings, schemas, or governance files unless explicitly assigned.
- Do not invent personal experiences, evidence, metrics, sources, or platform features.
- Do not copy protected third-party content.
- Do not include personal data, credentials, secrets, medical records, or financial records.
- Do not provide diagnosis, treatment, legal advice, or specific financial advice.
- Declare meaningful AI assistance in the pull request.
- Show the human contributor the complete diff before committing.
- Do not commit, push, or open a pull request until the human explicitly authorizes each action.
- Create one focused pull request and never merge it for the contributor.
- If the assigned file or a pull request for it already exists, stop and request another assignment.

## Validation

Confirm that only the assigned file changed, required headings are present, and the mission is actionable, safe, accessible, and tied to real-world growth.
